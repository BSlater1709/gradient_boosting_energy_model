# gradient_boosting_energy_model
UK electricity settlement price forecasting using calendar and lag features. Studied real time series data from Elexon BMRS, processed data and conducted exploratory analysis to understand the features of the dataset, including the weekday and seasonal volatility of the price. Built a naïve forecast to obtain baseline metrics, then fitted several regression models (variants of Gradient Boosting, Random Forest) on the data using calendar and lagged features for one step ahead prediction. Compared the performance metrics of each model, finding that the fitted models performed comparably to a simple baseline that uses the previous period's price, suggesting recent price history is the dominant signal in this dataset.
